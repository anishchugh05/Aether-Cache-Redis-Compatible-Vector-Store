The contradiction looked more like a match.

Real duplicates scored 0.73–0.92 similarity. Changing an API timeout from 30 to 60 seconds scored 0.94. That’s why Aether Cache only auto-merges near-identical text and lets the AI judge whether a new fact replaces an old one.
