Start with a fact worth remembering.

v0.1.2, available on PyPI

Everything runs on your machine. No account to create, no hosted memory service to configure.

1

A couple of prerequisites

Java 11+Any OS: adoptium.net

On macOS:

brew install openjdk@21
uv 
curl -LsSf https://astral.sh/uv/install.sh | sh
2

Install and connect

uv tool install aether-cache
aether-cache setup

Setup starts the engine in the background, downloads the embedding model once (~90 MB), and connects Claude Code, Cursor, and Codex automatically.

3

Give it something to remember

Open your AI tool in any project folder and say:

Remember that our tests need DOCKER_HOST set. It depends on docker-compose.yml.
  • aether-cache uiOpen the dashboard to review and fix memories.
  • aether-cache addAdd the project you're in so the dashboard checks its files.
  • aether-cache statusSee what’s running.
  • aether-cache doctorCheck everything and see how to fix problems.
  • aether-cache listInspect your saved memories.
