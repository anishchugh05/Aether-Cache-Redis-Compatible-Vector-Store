# Aether Cache is now Mnemolith

This project has a new name: **[Mnemolith](https://mnemolith.dev/)**. Same tool, same memories.

Move over with one command. It installs Mnemolith, removes `aether-cache`, moves your memories from
`~/.aether-cache` to `~/.mnemolith`, and reconnects your AI tools. Nothing is lost.

macOS or Linux:

```sh
curl -fsSL https://mnemolith.dev/install.sh | sh
```

Windows (PowerShell):

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://mnemolith.dev/install.ps1 | iex"
```

Until you do, this last version of `aether-cache` keeps your AI tools working by running Mnemolith underneath.
